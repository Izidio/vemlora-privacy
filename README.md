# VemloraApp — Política de Privacidade

Página HTML estática pública para o campo "URL da Política de Privacidade" do painel Meta for Developers.

## Publicação no endereço solicitado

URL esperada após configurar o GitHub Pages: **https://izidio.github.io/vemlora-privacy/**

1. Crie um repositório **público** na conta `Izidio`, chamado **exatamente** `vemlora-privacy`.
2. Adicione os arquivos `index.html`, `.nojekyll` e este `README.md` à raiz da branch `main`.
3. Em **Settings → Pages → Build and deployment → Source**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e clique **Save**.
4. Confirme que `https://izidio.github.io/vemlora-privacy/` abre a página sem login e sem erros.
5. No Meta for Developers → **Configurações do app**, cole a URL em **Política de Privacidade**. Salve e confira outros requisitos da área **Publicar**.

**Importante:** o site é público. Nunca publique `.env`, tokens, IDs secretos, logs ou arquivos de campanha junto com ele.

## Manutenção da política

- O texto descreve o uso restrito atual e as integrações previstas no `Izidio/meta-ads`.
- Antes de ampliar o público ou mudar dados processados, revise esta política.
- O canal de solicitação de dados está indicado como contato do Instagram `@vemlora.pets` e perfil GitHub `Izidio`; substitua por um endereço de e-mail institucional se preferir.
- Este texto é uma proposta técnica de transparência e não substitui avaliação jurídica ou de compliance.
